T1 · Cálculo Vectorial

Las 4 fórmulas estrella
$\vec{M}_P = \vec{r}_{PQ}\times\vec{F}$ (momento en P)
$\vec{M}_B = \vec{M}_A + \vec{r}_{BA}\times\vec{R}$ (cambio mom.)
$\tau = \vec{R}\cdot\vec{M}_P$ (invariante escalar)
$\vec{M}_{\min} = (\tau/|\vec{R}|^2)\vec{R}$ (mom. mínimo)
Eje central
$\vec{r}_0 = (\vec{R}\times\vec{M}_O)/|\vec{R}|^2$ (más cercano a O)
Recta: $\vec{r}(\lambda) = \vec{r}_0 + \lambda\vec{R}$
Pasa por X ⟺ $\vec{M}_X\parallel\vec{R}$ ⟺ $\vec{M}_X\times\vec{R}=\vec{0}$
Equiproyectiva (atajo)
$\vec{M}_A\cdot\vec{r}_{AB} = \vec{M}_B\cdot\vec{r}_{AB}$

T3 · Estática del Sólido

Equilibrio 2D
$\sum F_x = 0,\quad \sum F_y = 0,\quad \sum M_O = 0$
Apoyos (incógnitas)
  • Rodillo: 1 reacción ⊥ superficie
  • Pasador: $R_x, R_y$ (2)
  • Empotramiento: $R_x, R_y, M$ (3)
  • Cable / barra biart.: $T$ (1, alineada)
Cargas distribuidas (resultante)
Uniforme: $R = qL$ aplicada en el centro
Triangular: $R = q_0L/2$ a $L/3$ del lado pesado
Celosías
  • $m + 3 = 2n$ (isostática)
  • 2 barras nudo s/c → ambas nulas
  • 3 barras (2 colineales) → tercera nula
  • Ritter: corte por ≤3 barras + $\sum M$ donde se cruzan 2
Marco articulado
  • 4 incóg. globales → desensamblar por art. interna
  • Barra biart. sin carga → fuerza alineada con la barra
  • $\vec{C}$ opuesto en cada cuerpo (3ª ley)

T4 · Rozamiento

Coulomb
$F_r \le \mu_s N$ (reposo)
$F_r = \mu_s N$ (deslizamiento inminente)
$\phi_s = \arctan\mu_s$ (cono autoblocante)
Vuelco vs deslizamiento
Desl: $F = \mu Mg$
Vuelco: $\sum M_{arista}=0$ con $N$=0 al otro lado
Crítico = el menor
Sistema disco + barra + muelle
  • $F_r = \mu N$ solo donde desl. inminente
  • Disco con cuerda: $T$ a periferia → $M = T\cdot R$
  • Disco con par P (2 contactos): $P = (F_{r1}+F_{r2})\cdot R$
  • Doble sentido: 2 cálculos con $F_r$ opuesta
Tornillo de potencia
$M_{avance} = W\,r_m\tan(\lambda+\phi_s)$
$M_{ret} = W\,r_m\tan(\phi_s-\lambda)$
Autoblocante: $\lambda<\phi_s$

T5 · Cables

Catenaria — 3 fórmulas mágicas
$y = a(\cosh(x/a)-1)$, $a = H/w$
$s = a\sinh(x/a)$ (longitud arco)
$T = w(y+a)$ (tensión)
Truco: $s^2 = y^2 + 2ay$
Parábola (carga uniforme horizontal)
$y = wx^2/(2H)$
$H = wL^2/(8d)$
$T_{max} = \sqrt{H^2 + (wL/2)^2}$
Longitud: $s\approx L(1 + 8d^2/(3L^2))$
Polea con rozamiento
$T_2/T_1 = e^{\mu\beta}$ (Euler-Eytelwein)
$\beta$ = ángulo envoltura · $T_2 > T_1$
Cable con cargas puntuales
  • Tramos rectos entre cargas
  • $H$ horizontal constante en todos los tramos
  • $T_i = H/\cos\theta_i$

T6 · Resistencia de Materiales

Fórmulas estrella
$\sigma = My/I$ (Navier)
$\sigma_{max} = M/W_f$ con $W_f = I/c$
$dV/dx = -q$, $dM/dx = V$
$\tau = VQ/(Ib)$ (Jouravski)

$\sigma = F/A$, $\tau = V/A$ (cortadura media)
$\sigma = E\varepsilon$, $\delta = FL/(AE)$
$G = E/[2(1+\nu)]$, $\nu_{acero}\approx 0{,}3$
Acero: $E\approx 210$ GPa, $G\approx 80$ GPa

T7 · Cinemática del Sólido

Campo velocidades y aceleraciones
$\vec{v}_B = \vec{v}_A + \vec{\omega}\times\vec{r}_{AB}$
$\vec{a}_B = \vec{a}_A + \vec{\alpha}\times\vec{r}_{AB} - \omega^2\vec{r}_{AB}$
Composición de movimientos
$\vec{\omega}_{2/0} = \vec{\omega}_{2/1} + \vec{\omega}_{1/0}$
$\vec{\alpha}_{2/0} = \vec{\alpha}_{2/1} + \vec{\alpha}_{1/0} + \vec{\omega}_{1/0}\times\vec{\omega}_{2/1}$
↑ término cruzado (no olvidar)
Coriolis (deslizadera)
$\vec{a}_{Cor} = 2\vec{\omega}\times\vec{v}_{rel}$
$\vec{a}_{abs} = \vec{a}_{arr} + \vec{a}_{rel} + \vec{a}_{Cor}$
CIR — localización
  • Intersección perpendiculares a $\vec{v}$ de 2 puntos
  • $v_A = \omega\cdot r_{IA}$
  • Rodadura sin desl.: CIR = punto de contacto
Rotación pura, eje fijo
$v = r\omega$
$a_t = r\alpha$ (tangencial), $a_n = r\omega^2$ (centrípeta)
Radio curv.: $\rho = v^2/a_n$
Engranajes / poleas
$r_A\omega_A = r_B\omega_B$
Ext: sentidos opuestos · Int: mismo
$i = \omega_A/\omega_B = r_B/r_A = N_B/N_A$

T8 · Movimiento Plano (Dinámica)

Newton-Euler
$\sum\vec{F} = m\vec{a}_G$
$\sum M_G = I_G\,\alpha$

Sólido$I_G$
Barra $L$$mL^2/12$
Disco $R$$mR^2/2$
Aro $R$$mR^2$
Esfera $R$$2mR^2/5$

Energía cinética y Trabajo-Energía
$T = \frac{1}{2}mv_G^2 + \frac{1}{2}I_G\omega^2$
Rodadura: $T = \frac{1}{2}I_P\omega^2$, $I_P = I_G+mR^2$
$T_1 + \sum U_{1\to 2} = T_2$
$U_{peso} = -mg\Delta y$, $U_k = -\frac{1}{2}k(x_2^2-x_1^2)$
Rozamiento en rodadura: NO trabaja
Impulso-momento
$m\vec{v}_{G1} + \int\vec{F}\,dt = m\vec{v}_{G2}$
$I_G\omega_1 + \int M_G\,dt = I_G\omega_2$
Disco rodando — atajos
  • $v_G = R\omega$, $a_G = R\alpha$
  • Pto. contacto: $v=0$ pero $a = R\omega^2$ (centrípeta)
  • Plano inclinado h, disco macizo: $v_G = \sqrt{4gh/3}$
