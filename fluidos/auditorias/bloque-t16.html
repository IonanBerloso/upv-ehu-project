T16 · Análisis dimensional

Manual práctico — 5 tipos de problema (Buckingham Π, repetidoras, grupos típicos, similitud, aplicaciones de examen)

📖 Cómo usar esta guía

El análisis dimensional aparece en CASI TODOS los exámenes (junio 2020-2025) como pregunta independiente. La metodología es casi mecánica: identificar variables, contar dimensiones, elegir repetidoras, formar grupos.

Estrategia: aprende los 4 pasos del Tipo 01 + las dimensiones de las variables comunes (Tipo 03). El resto son adaptaciones a aplicaciones concretas.

📑 Índice de tipos de problema

  1. Buckingham Π — Plantilla genérica (4 pasos)
  2. Elección de variables repetidoras
  3. Grupos adimensionales típicos (Re, Eu, Fr, We, Ma)
  4. Similitud dinámica modelo ↔ prototipo
  5. Aplicaciones de examen (bomba, ala, vertedero)
Tipo 01 · Buckingham

Teorema Π de Buckingham — plantilla mecánica de 4 pasos

★★★ IMPRESCINDIBLEAparece en TODOS los exámenes
👁️ Cómo lo reconozco
  • Te dan una lista de variables físicas que afectan a un fenómeno (típicamente 5-8 variables).
  • Te piden los grupos adimensionales que describen el problema.
  • Aparecen palabras: "análisis dimensional", "Buckingham", "grupos Π", "variables repetidoras".
📐 Teoría imprescindible
  • Teorema Π de Buckingham: si un fenómeno depende de $n$ variables y se usan $r$ dimensiones independientes, el problema se puede escribir con $k = n - r$ grupos adimensionales $\Pi_1, \Pi_2, ..., \Pi_k$.
  • En MF las dimensiones fundamentales son típicamente 3: $M$ (masa), $L$ (longitud), $T$ (tiempo). Por tanto $r = 3$ generalmente.
  • Las variables repetidoras son $r$ variables (3 normalmente) que aparecen en TODOS los grupos $\Pi$. Deben ser dimensionalmente independientes entre sí.
  • Cada grupo $\Pi_i$ se forma combinando una variable NO repetidora con las $r$ repetidoras hasta hacerla adimensional.
📋 Fórmulas clave
Número de grupos adimensionales
$$k = n - r$$
$n$ = nº de variables del problema, $r$ = nº de dimensiones fundamentales (típicamente 3 en MF).
Forma de cada grupo Π
$$\Pi_i = X_i \cdot V_a^{\alpha_i} V_b^{\beta_i} V_c^{\gamma_i}$$
$X_i$ = variable no repetidora, $V_a, V_b, V_c$ = repetidoras. Los exponentes $\alpha, \beta, \gamma$ se determinan imponiendo que $[\Pi_i] = M^0 L^0 T^0$.
⚙️ Los 4 pasos genéricos
  1. Identificar las $n$ variables que intervienen en el problema (incluida la incógnita).
  2. Determinar las dimensiones fundamentales (en MF normalmente $r = 3$: M, L, T).
  3. Elegir $r$ variables repetidoras dimensionalmente independientes (que NO formen ya un grupo $\Pi$ entre sí). Suelen tomarse: una geométrica ($D$ o $L$), una cinemática ($v$ o $\omega$), una dinámica ($\rho$ o $\mu$).
  4. Combinar cada variable NO repetidora con las repetidoras: imponer $[\Pi_i] = M^0 L^0 T^0$ y resolver el sistema lineal de exponentes. Resultado: $k = n - r$ grupos.
⚠️ Errores frecuentes
  • Olvidar contar la incógnita como una de las $n$ variables.
  • Elegir repetidoras NO independientes (forman ya un grupo $\Pi$): el método falla.
  • Mezclar dimensiones fundamentales (si usas FLT en lugar de MLT, $r$ sigue siendo 3, pero las dimensiones cambian).
  • Olvidar variables que ya son adimensionales (ángulo $\theta$): no entran en el conteo $n$, son ya un $\Pi$ por sí mismas.

Tipo 02 · Repetidoras

Elección de variables repetidoras

Crítico — define todo el problema
👁️ Cómo lo reconozco
  • El enunciado a veces te dice qué repetidoras usar ("variables repetidas: $D$, $\rho$, $v$").
  • Otras veces tienes que elegirlas tú.
  • La elección AFECTA a la forma de los $\Pi$, pero no al número.
📐 Teoría imprescindible
  • Las repetidoras tienen que ser dimensionalmente independientes: que no formen ya un grupo $\Pi$ entre ellas.
  • Combinación clásica en MF: una geométrica ($D$, $L$) + una cinemática ($v$, $\omega$, $a$) + una propiedad del fluido ($\rho$, $\mu$).
  • Tradicionalmente NO se elige la incógnita como repetidora (porque entonces aparecería como repetidora en TODOS los $\Pi$ y no se "aislaría" en uno solo).
📋 Combinaciones típicas
Combinación clásica (problema general MF)
$$\{D,\ v,\ \rho\} \quad \text{o} \quad \{L,\ v,\ \rho\}$$
Conduce naturalmente a Re, Eu, Fr como grupos típicos.
Para problemas con bombas / turbinas
$$\{D,\ \omega,\ \rho\}$$
Conduce a coeficientes de bomba $C_Q = Q/(\omega D^3)$, $C_H = gH/(\omega^2 D^2)$, $C_P = P/(\rho \omega^3 D^5)$.
⚙️ Pasos para elegir repetidoras
  1. Listar todas las variables y sus dimensiones.
  2. Identificar las dimensiones fundamentales presentes (M, L, T).
  3. Elegir 3 variables tales que entre ellas aparezcan TODAS las dimensiones fundamentales y NO formen un grupo Π entre sí.
  4. NO elegir como repetidora la variable de la que quieres "aislar" el comportamiento (incógnita principal).
  5. Verificar independencia: la matriz de exponentes de las repetidoras debe ser de rango $r$.
⚠️ Errores frecuentes
  • Elegir 3 longitudes (D, L, h) → dimensionalmente dependientes (todas son L).
  • Elegir la incógnita como repetidora: no la podrás aislar en un único Π.
  • Si el enunciado especifica las repetidoras, NO las cambies (aunque tu elección "natural" sea otra).

Tipo 03 · Grupos típicos

Grupos adimensionales clásicos (Re, Eu, Fr, We, Ma, St)

★★★ Memorizar
👁️ Cómo lo reconozco
  • El examen pregunta el "significado físico" de un grupo Π.
  • Tienes que interpretar qué fuerzas relacionan los grupos obtenidos.
  • O directamente identificar Re, Eu, etc. en una lista de grupos.
📐 Teoría imprescindible — significado físico
  • Cada grupo adimensional clásico es un cociente de dos fuerzas características.
  • Re (Reynolds): inercia / viscosidad. Régimen laminar/turbulento.
  • Fr (Froude): inercia / gravedad. Canales abiertos, flotación de barcos.
  • Eu (Euler): presión / inercia. Hidráulica, presión dinámica.
  • We (Weber): inercia / tensión superficial. Gotas, burbujas, atomización.
  • Ma (Mach): velocidad / sonido. Compresibilidad de gases.
  • St (Strouhal): tiempo característico / período. Oscilaciones (vórtices).

⚙️ Pasos para identificar / interpretar grupos
  1. Comparar el grupo obtenido con los clásicos de la tabla.
  2. Si coincide: nombrarlo y dar su significado físico.
  3. Si no coincide pero es un producto/cociente de clásicos: descomponerlo.
  4. Si es completamente nuevo: interpretar qué fuerzas o efectos compara según las variables que contiene.
⚠️ Errores frecuentes
  • Confundir Re ($\rho v L/\mu$) con Re cinemático ($v L/\nu$) — son IGUALES, $\nu = \mu/\rho$.
  • Olvidar que Eu se define a veces con el factor $1/2$ (presión dinámica).
  • Mezclar Mach con velocidad supersónica (Ma > 1 = supersónico).

Tipo 04 · Similitud

Similitud dinámica modelo ↔ prototipo

★★ Frecuencia: media-alta
👁️ Cómo lo reconozco
  • Se ensaya un modelo a escala (1:50, 1:100) y te piden los resultados en el prototipo real.
  • Aparecen palabras "modelo", "prototipo", "escala", "similitud", "ensayo".
  • Aplicaciones: barcos (Fr), tuberías (Re), aviones (Ma), vertederos (Fr).
📐 Teoría imprescindible
  • Similitud geométrica: mismas proporciones (escala lineal $\lambda = L_m/L_p$).
  • Similitud cinemática: mismos campos de velocidades adimensionales.
  • Similitud dinámica: los grupos $\Pi$ relevantes son iguales en modelo y prototipo.
  • Si el fenómeno está dominado por inercia/viscosidad: $Re_m = Re_p$. Si por gravedad: $Fr_m = Fr_p$. Etc.
  • NO siempre se pueden cumplir todos los grupos a la vez (incompatibilidad entre Re y Fr en barcos: se elige uno y se corrige el otro empíricamente).
📋 Fórmulas clave
Similitud por Reynolds
$$\frac{\rho_m v_m L_m}{\mu_m} = \frac{\rho_p v_p L_p}{\mu_p}$$
Si mismo fluido: $v_m / v_p = L_p / L_m$ (modelo más pequeño → velocidad mayor).
Similitud por Froude
$$\frac{v_m}{\sqrt{g L_m}} = \frac{v_p}{\sqrt{g L_p}} \quad \Rightarrow \quad v_m = v_p \sqrt{L_m/L_p}$$
Modelo más pequeño → velocidad MENOR (factor $\sqrt{\lambda}$).
Escalas derivadas (similitud por Froude)
$$\frac{Q_m}{Q_p} = \lambda^{5/2} \qquad \frac{F_m}{F_p} = \lambda^3 \qquad \frac{P_m}{P_p} = \lambda^{7/2}$$
⚙️ Pasos de resolución
  1. Identificar el grupo Π relevante (Re para tuberías, Fr para canales/barcos, etc.).
  2. Igualar ese grupo entre modelo y prototipo: $\Pi_m = \Pi_p$.
  3. Despejar la velocidad u otra magnitud del modelo en función del prototipo.
  4. Para magnitudes derivadas (Q, F, P): usar las relaciones de escala correspondientes.
  5. Para resultados al prototipo: medir en el modelo y aplicar la escala inversa.
⚠️ Errores frecuentes
  • Aplicar similitud Re cuando el fenómeno depende de Fr (canal abierto) o viceversa.
  • Pretender cumplir Re y Fr a la vez con el mismo fluido (imposible si $L_m \neq L_p$).
  • Confundir las escalas derivadas: $Q_m/Q_p \neq \lambda^3$ (depende del régimen).

Tipo 05 · Aplicaciones

Aplicaciones típicas de examen — Bomba · Ala · Vertedero · Compuerta

junio2024ef, junio2025ef, mayo2025
👁️ Cómo lo reconozco
  • El enunciado describe una aplicación concreta (bomba, ala de avión, vertedero en V, compuerta) y pide los grupos adimensionales.
  • Te dan una lista clara de variables y, a veces, las repetidoras.
📐 Teoría imprescindible — combinaciones por aplicación
  • Bomba/turbina: variables = {Q, H, P, ρ, μ, ω, D}. Repetidoras = {ρ, ω, D}. Grupos = $C_Q$, $C_H$, $C_P$, Re.
  • Ala de avión: variables = {F, ρ, v, c, μ, c_{son}}. Grupos = $C_L$, Re, Ma.
  • Vertedero: variables = {Q, H, b, ρ, g, μ}. Grupos = $C_d$, Re, Fr.
  • Compuerta en tubería: variables = {ΔP, v, D, h, ρ, μ, θ}. Grupos = Eu, Re, h/D, θ.
📋 Coeficientes adimensionales por aplicación
Bomba — coeficientes característicos
$$C_Q = \frac{Q}{\omega D^3} \quad C_H = \frac{gH}{\omega^2 D^2} \quad C_P = \frac{P}{\rho \omega^3 D^5}$$
Ala — coeficientes aerodinámicos
$$C_L = \frac{F_L}{\frac{1}{2}\rho v^2 A} \quad C_D = \frac{F_D}{\frac{1}{2}\rho v^2 A}$$
Vertedero — coeficiente de descarga
$$C_d = \frac{Q}{\sqrt{g}\,b\,H^{3/2}}$$
⚙️ Pasos de resolución
  1. Reconocer el tipo de aplicación y sus variables características.
  2. Aplicar Buckingham con las repetidoras adecuadas.
  3. Identificar los grupos resultantes con los coeficientes clásicos de la aplicación (CQ, CH, CL, Cd...).
  4. Si te piden interpretar: dar el significado físico de cada grupo.
  5. Si te piden similitud: igualar los grupos relevantes entre modelo y prototipo.
⚠️ Errores frecuentes
  • Olvidar que Q ya está incluido como variable cuando se busca $C_Q$.
  • Confundir coeficientes $C_L$ (sustentación) y $C_D$ (resistencia) de un ala.
  • Para vertederos: incluir $\mu$ cuando el flujo es turbulento (Re alto), donde $\mu$ no influye.
